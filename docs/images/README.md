# Repository Images Directory

This directory is designated for storing all visual assets used in the project documentation (such as the main `README.md` and architecture descriptions).

## Expected Assets
- **`homepage.png`**: Screenshot of the main dashboard UI.
- **`chat.png`**: Screenshot of the conversational RAG chatbot interface with citation modals.
- **`upload.png`**: Screenshot of the PDF document upload and ingestion system.
- **`architecture.png`**: High-level component relationship diagram.
- **`deployment.png`**: Diagram showing production multi-stage container isolation and environment structure.
